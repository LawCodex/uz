# О ратификации Конвенции о Межпарламентской Ассамблее государств — участников Содружества Независимых Государств (Минск, 26 мая 1995 года)

Принят Законодательной палатой 22 февраля 2019 года

Одобрен Сенатом 28 февраля 2019 года

Ратифицировать Конвенцию о Межпарламентской Ассамблее государств-участников Содружества Независимых Государств (Минск, 26 мая 1995 года) со следующей оговоркой:

«Республика Узбекистан будет выделять средства для финансирования деятельности Межпарламентской Ассамблеи государств-участников Содружества Независимых Государств в объемах, необходимых для содержания в ней своих представителей».

Президент Республики Узбекистан Ш. МИРЗИЁЕВ

г. Ташкент,

4 марта 2019 г.,

№ ЗРУ-523

> (Национальная база данных законодательства, 05.03.2019 г., № 03/19/523/2698)
