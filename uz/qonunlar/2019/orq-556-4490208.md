# Халқаро меҳнат ташкилотининг саноат ва савдода меҳнат инспекцияси тўғрисидаги 81-сонли Конвенциясини (Женева, 1947 йил 11 июль) ратификация қилиш ҳақида

Қонунчилик палатаси томонидан 2019 йил 3 июлда қабул қилинган

Сенат томонидан 2019 йил 24 августда маъқулланган

Халқаро меҳнат ташкилотининг саноат ва савдода меҳнат инспекцияси тўғрисидаги 81-сонли Конвенцияси (Женева, 1947 йил 11 июль) ратификация қилинсин.

Ўзбекистон Республикасининг Президенти Ш. МИРЗИЁЕВ

Тошкент ш.,

2019 йил 27 август,

ЎРҚ-556-сон
